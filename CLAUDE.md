# Rules
- The Figma UI kit is the source of truth for the design system
- Screens in Figma use only library components, auto layout, and tokens instead of raw values
- Every component in src/components/ui has a story in Storybook
- Design system changes go through a separate branch and PR

# Skills
- Screens in Figma: figma-generate-design (+ figma-use)
- Component mapping: figma-code-connect
- Prototype from Figma: figma-design-to-code
